# React + Vite + Tailwind CSS

A minimal React starter using Vite and Tailwind CSS v4.

## Requirements

- Node.js 20 or newer
- npm

## Install

~~~bash
cd frontend
npm install
~~~

## Development

~~~bash
npm run dev
~~~

## Production build

~~~bash
npm run build
~~~

Tailwind CSS v4 is configured through the official Vite plugin in `frontend/vite.config.js` and imported in `frontend/src/styles.css`. Start building in `frontend/src/App.jsx`.
